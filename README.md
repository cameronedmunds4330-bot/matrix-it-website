# Matrix I.T. & Cybersecurity — Website (Draft)

Rough draft of the website for Matrix I.T. & Cybersecurity, a managed IT support and cybersecurity provider based in Lehi, Utah.

**Status:** Work in progress. Content, contact form, and branding are still being finalized.

## Pages
- `index.html` — Home
- `services.html` — Services and coverage tiers
- `about.html` — About the company
- `contact.html` — Contact and risk assessment request form

## Tech
Plain HTML, CSS, and JavaScript. No build step. Open `index.html` in a browser to view locally.
